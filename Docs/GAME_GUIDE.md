# Shadow Arena - game guide

## Run it
1. Open `E:\Godot\Godot_v4.7.2-stable_win64.exe`.
2. Import `E:\ShadowArena\Game\project.godot` (first time only), then press F5.
3. Menu: pick a loadout, then PLAY.

## Controls
| Action | Key |
|---|---|
| Move / look | W A S D / mouse |
| Fire / aim | Left mouse / right mouse (hold) |
| Sprint / crouch / jump | Shift / Ctrl or C (hold) / Space |
| Reload / fire mode | R / B |
| Switch weapon | 1, 2, Q or mouse wheel |
| First / third person | V |
| Scoreboard / pause | Tab (hold) / Esc |

## Rules
- 4 v 4: you + 3 bots (team SHAHEEN, blue) against 4 bots (MARKHOR, orange).
- First to 40 kills, or the leader after 10 minutes.
- Respawn 1.5 s after death at the safest spawn point; 2 s spawn protection.
- Health regenerates after 5 s without taking damage. No friendly fire.

| `scripts/weapons/weapon.gd` | Ammo, fire modes, fire rate, spread, recoil, reload. |
| `scripts/weapons/bullet_manager.gd` | Hitscan rays and simulated sniper bullets (speed + drop). |
| `scripts/combat/combatant.gd` | Base fighter: health, team, weapons, movement, death, respawn. |
| `scripts/player/player_controller.gd` | Input, camera (FP/TP), view recoil, first-person gun. |
| `scripts/ai/bot_controller.gd` | Bot state machine: advance, hold, engage, hunt, cover. |
| `scripts/game_mode/tdm_match.gd` | Match rules, spawns, scoring, bot blackboard, navigation bake. |
| `scripts/game_mode/arena_env.gd` | Sky, sun, fog, post-processing, weather presets. |
| `scripts/combat/vfx.gd` | Impacts, bullet holes, tracers, muzzle flash, casings (all pooled). |
| `scripts/core/game.gd` | Settings, loadout, quality presets, scene switching (autoload). |
| `scripts/core/sfx.gd` | Sounds: recordings from `assets/audio/` plus synthesised UI/reload sounds (autoload). |
| `scripts/combat/character_visual.gd`, `aim_modifier.gd` | The animated soldier and its aim pose. |
| `scripts/weapons/weapon_visual.gd` | Loads each gun model and adds scope / muzzle attachments. |
| `scripts/ui/*.gd` | HUD, main menu, loadout panel, settings panel. |
| `scenes/maps/arena.tscn` | The map. Generated by `MapSource/gen_arena.py`. |

Health is 100. Headshot multipliers: AR 1.8, SMG 1.6, sniper 2.5,
shotgun 1.25, pistols 1.8 / 2.1. Damage falls off with distance.
Snipers fire real projectiles (790 / 910 m/s) that drop with gravity; all
other weapons are hitscan.

## Bots
- See only inside a ~145 degree cone and their sight range, and need line of sight.
- React after a delay, then aim with an error that shrinks while tracking.
- Roles from their weapon: snipers hold the nests and roofs, SMG/shotgun
  bots take the flanks, rifles push the middle.
- Share sightings with their team, turn towards gunfire (suppressors cut
  the hearing range from 45 m to 12 m), run to cover when hurt or reloading.
- Never enter the enemy spawn zone.
- Difficulty (Settings): Easy / Normal / Hard changes reaction, aim error and turn speed.

## How it was tested
Automated runs in Godot 4.7.2 without a display:
- Full bot matches on all three difficulties ran to 40 kills with no script errors.
- Scripted player test: auto fire, recoil, reload, ADS zoom, weapon switch,
  headshot kill and scoring, sniper travel time and damage, scope,
  third-person camera, death and respawn, pause, match end screen.
- Navigation: paths exist from spawn to spawn, both roofs, both nests and the shed.
- A few screenshots rendered with a software OpenGL renderer to check the look.

Not tested: real mouse feel, sound by ear, frame rate, and the Mobile
(Vulkan) renderer on your GPU.
