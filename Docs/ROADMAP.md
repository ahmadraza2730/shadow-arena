# Roadmap

Status key: [x] built and tested by automated runs, [~] built but needs
your eyes/hands on a real PC, [ ] not started.

- [x] 1. Project setup, Git, folder structure, version control
- [x] 2. Character controller: move, sprint, crouch, jump, camera, ADS
- [x] 3. Base weapon system: hitscan, recoil, spread, reload, fire modes
- [x] 4. Weapon data table (9 weapons), sniper bullet travel and drop
- [x] 5. Attachments (11) and loadout screen
- [x] 6. Health, damage, headshots, hit markers, death, respawn
- [x] 7. TDM mode: teams, score, timer, safe spawns, scoreboard, kill feed
- [x] 8. Map gray-box (120 x 120 m) - see MAP.md
- [x] 9. Bot AI: navigation, cover, aiming, roles, shared sightings
- [~] 10. Art pass: generated texture sets (colour/normal/roughness) on every
        surface, set dressing, cloud sky, sun, fog, bloom, 3 weather presets.
        No imported models yet, no baked lightmaps.
- [~] 11. Animation, sound, VFX: all procedural placeholders (box soldier,
        box guns, synthesised sounds, pooled particles/decals/tracers).
- [x] 12. HUD, main menu, pause menu, settings, end screen
- [~] 13. Low/Medium/High presets are in. FPS has not been measured on the
        target laptop - see GRAPHICS.md for the tuning plan.
- [ ] 14. Online multiplayer (deliberately not started: offline must be
        play-tested and approved first)
- [~] 15. Export preset is ready; the build itself must be made on your PC
        (PACKAGING.md).
